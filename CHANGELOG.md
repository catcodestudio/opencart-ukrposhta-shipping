# Ukrposhta Shipping — OpenCart 4.x

## 1.2.2 — 2026-09-22
- Працює на CatCode One Page Checkout (маршрут `extension/cc_onepage/checkout`) так само, як на штатному чекауті: віджет область → місто → відділення монтується, стартова адреса засівається. Раніше перевірка маршруту пускала лише `checkout/checkout`.
- На One Page Checkout віджет не відновлює метод доставки/оплати після `register.save` паралельно з самим чекаутом (той робить це у своїй черзі) — через перегони список оплат порожнів із «Потрібний спосіб доставки!».
- OpenCart 4.1: підбір області падав з `Unknown column 'name'` (назви зон у 4.1 у `zone_description`). Зони тепер читаються через модель ядра `localisation/zone` — однаково на 4.0 і 4.1.
